# Tiny Games

Two small browser games, each a single self-contained HTML file — no build step, no dependencies, no assets.

## The games

- **Orbit Golf** (`orbit-golf.html`) — 2D gravity golf in space: slingshot a ball past planets whose gravity bends your shot, across 10 procedural levels with par scoring.
- **Wanderland** (`world.html`) — a cute side-scrolling exploration and building toy: wander an endless world of four biomes, place flowers, lanterns and signs, and watch the day/night cycle roll by.

## How to run

Open `index.html` in any modern browser for a landing page linking to both games, or open either game's HTML file directly. No server is required, but if you prefer one:

```sh
python3 -m http.server
# then visit http://localhost:8000
```
